# 파일 형식별 미리보기

## 열기

**파일 열기**(`Ctrl+O`)를 누르거나 파일을 창에 끌어놓으면 미리봅니다. 실행 파일에 파일 경로를 전달하거나 탐색기 Space 미리보기를 사용할 수도 있습니다. 이미지의 **더보기**에서 원본 크기, 회전, 지원 형식의 변환 저장을 찾을 수 있습니다.

## PDF·오디오·동영상·이미지·글꼴

- PDF는 한 페이지씩 표시합니다. 하단의 **이전**, **다음**으로 이동합니다. 암호로 잠긴 문서는 열리지 않습니다.
- MP4·M4V·MOV·MKV·AVI·WMV·WebM·MPEG와 MP3·WAV·M4A·AAC·FLAC·WMA·OGG·Opus·AIFF는 Windows 미디어 코덱으로 엽니다. 코덱과 파일 인코딩에 따라 재생 가능한 범위가 다릅니다. **재생**을 눌러 시작하고 재생 위치를 옮길 수 있습니다.
- 아래 이미지 형식 표에서 지원 확장자와 미리보기 방식을 확인할 수 있습니다.
- TTF·OTF는 파일의 글꼴 이름과 글자 견본을 표시합니다. 글꼴 설치 없이 사용할 수 있습니다.

## 이미지 형식

| 형식 | 미리보기 |
| --- | --- |
| JPEG·JFIF (`.jpg`, `.jpeg`, `.jfif`, `.jif`, `.jpe`), BMP, PNG, GIF, TIFF | 정지 이미지를 확대·회전하며 확인합니다. TIFF는 첫 페이지를 표시합니다. |
| WebP, AVIF, APNG, SVG, ICO, 애니메이션 GIF와 PNG | WebView2에서 표시합니다. SVG의 외부 리소스와 스크립트는 실행되지 않습니다. |
| BPG | 8~14비트 정지 이미지와 8비트 애니메이션을 표시합니다. 높은 비트 심도의 애니메이션은 첫 프레임을 표시합니다. |
| PSD·PSB, DDS, JPEG XR(`.jxr`, `.wdp`, `.hdp`), JPEG 2000(`.jp2`, `.j2k`, `.j2c`, `.jpc`), JPEG XL(`.jxl`) | PSD의 합성 이미지와 다른 형식의 대표 이미지를 표시합니다. |
| EXR, Radiance HDR(`.hdr`, `.rgbe`), HEIC(`.heic`, `.heif`, `.hif`), QOI, TGA, PCX, Netpbm(`.pbm`, `.pgm`, `.pnm`, `.ppm`, `.pam`) | 대표 이미지를 표시합니다. HDR 자료는 SDR 미리보기로 표시합니다. |
| 카메라 RAW | DNG, CR2, CR3, CRW, NEF, NRW, ORF, RW2, PEF, SR2, ARW, RAF 등은 LibRaw가 인식하는 모델과 압축 방식에서 열립니다. |
| Clip Studio Paint (`.clip`) | 파일에 저장된 캔버스 미리보기를 읽습니다. 저장된 미리보기가 없는 파일과 레이어 편집은 지원 범위에 포함되지 않습니다. |

큰 GIF·PNG 애니메이션은 파일이 32 MB를 넘으면 첫 프레임을 표시합니다. BPG는 한 프레임 최대 419만 픽셀, 프레임 합계 최대 1,600만 픽셀 한도가 있으며 디코더의 메모리 한도도 적용됩니다. DDS의 GPU 텍스처 압축 변형 및 최신 RAW 카메라별 지원 범위는 디코더에 따라 다릅니다.

## 압축 내부 보기

ZIP·RAR·7Z·TAR·TAR.GZ(TGZ)와 CBZ·CBR·CB7을 열면 왼쪽에 내부 경로와 크기가 표시됩니다. EPUB·JAR·APK·ODT·ODS·ODP·NUPKG·VSIX·WHL·KMZ는 ZIP 구조를 목록으로 표시합니다.

- 파일을 고르면 이미지·PDF·문서·Rive·텍스트 또는 파일 정보를 표시합니다. HTML과 XML은 원문 텍스트로 표시합니다.
- 솔리드 압축, 분할 항목과 링크는 목록과 항목 정보를 표시합니다. 암호화·손상 항목은 해당 항목에 오류 안내를 표시합니다.
- 디스크에 압축을 풀지 않으며 원본이 바뀌었다면 다시 열어 갱신합니다.
- 중첩 압축, ZIP64, 분할 ZIP 및 압축 내부의 오디오·동영상 재생과 글꼴 견본은 지원 범위에 포함되지 않습니다.

## 파일 정보와 텍스트

전용 미리보기가 없는 형식은 UTF-8 또는 BOM이 있는 UTF-16/UTF-32로 읽을 수 있으면 원문을 표시합니다. 그 밖의 바이너리에는 파일명·크기·수정 시각과 앞 1,024바이트의 16진수 보기를 제공합니다. 폴더를 창에 끌어 놓으면 바로 아래 항목을 최대 500개 표시합니다.

## 마크다운 보기와 테마

`.md` 파일은 제목·굵게/기울임·목록·인용·표·코드 블록을 서식으로 표시합니다. ZIP 안의 `.md`도 동일하게 표시합니다. 상단 `원문 보기`를 켜면 마크다운 문법을 그대로 확인하고 복사할 수 있습니다.

**설정 → 마크다운 → 테마**에서 **다크 / 라이트 / 세피아**를 선택합니다. 배경·본문·링크 표시·코드·표·인용문에 즉시 반영되며 읽던 위치와 선택 영역을 유지합니다. 원문 보기에도 같은 색상을 적용합니다.

선택한 테마는 `%LOCALAPPDATA%\MoaView\markdown-theme.json`에 저장되어 새 창과 다음 앱 실행에 적용됩니다. 기본은 다크입니다. 설정이 없거나 손상되면 기본값으로 열며, 저장할 수 없는 경우 현재 창에 적용하고 저장 실패 안내를 표시합니다. `원문 보기` 선택은 현재 창에서만 유지합니다.

Markdig 1.5.1로 구문을 읽고 WPF로 표시하므로 추가 브라우저 런타임이 필요하지 않습니다. HTML은 원문으로 표시하며 실행하지 않습니다. 링크는 텍스트와 주소 툴팁으로 표시하고 자동 링크는 주소를 표시합니다. 클릭으로 외부 사이트를 열지 않으며, 이미지 문법은 이미지를 가져오지 않고 대체 텍스트로 표시합니다. Mermaid·수식·각주 등 고급 확장은 렌더링하지 않습니다.

서식 보기는 앞 10만 자까지 표시하고 생략 안내를 제공합니다. 문서 구조가 너무 복잡한 경우 원문 보기로 확인하도록 안내합니다. 원문은 기존 텍스트 한도(4 MB, 30만 자)를 따릅니다. 원본 파일 내용은 변경하지 않습니다.

## 오피스와 한글 내용 보기

원본 페이지의 모양보다 내용을 확인하는 미리보기입니다. 앱 안에서 본문을 표시하며 Office 또는 한글 프로그램을 실행하지 않습니다.

| 형식 | 표시 내용 | 주요 제한 |
| --- | --- | --- |
| DOCX | 본문 문단, 표의 텍스트와 셀 구분 | 페이지 배치·글꼴·이미지·머리말·각주·메모 제외 |
| XLSX | 실제 시트 순서, 시트명, 셀 주소, 저장된 값, 수식 텍스트 | 수식 재계산 없음, 숫자 서식과 날짜 표시 형식 재현 안 함, 차트 제외 |
| PPTX | 문서에 선언된 슬라이드 순서, 텍스트와 표 | 슬라이드 도형 배치·이미지·동영상·전환 효과·발표자 노트 제외 |
| HWP 5.x | 구역별 본문과 표 안의 텍스트 | 표의 행·열/병합 셀 배치는 평탄화, 이미지·수식 제외 |
| HWPX | 문서에 선언된 구역 순서, 본문·표 텍스트 | 페이지 배치·이미지·도형 제외 |

상단 선택 상자로 구역·시트·슬라이드를 바꿉니다. 긴 줄은 가로 스크롤로 확인하고 텍스트를 선택·복사할 수 있습니다. 시트의 수식은 문서에 저장된 결과를 보여주므로 마지막 저장 이후 재계산이 필요한 값은 최신 결과와 다를 수 있습니다.

구형 DOC·XLS·PPT, 매크로 형식 DOCM·XLSM·PPTM, HWP 3.x/이전 버전은 지원하지 않습니다. 암호화 Office 문서, 암호·배포용·DRM 보호 HWP, 암호화 ZIP 기반 문서는 해제하지 않고 안내합니다. 외부 문서 관계를 가져오거나 매크로·스크립트·포함 개체를 실행하지 않습니다.

## Rive 애니메이션 보기

`.riv`를 열면 기본 아트보드와 첫 상태 머신(없으면 첫 애니메이션)이 표시됩니다.

- `아트보드`: 파일에 포함된 다른 아트보드로 변경
- `재생` 선택 상자: 상태 머신 또는 타임라인 애니메이션 변경
- `일시정지` / `재생`: 재생 상태 전환
- `처음부터`: 현재 선택 재시작

상태 머신의 포인터 상호작용을 사용할 수 있습니다. 모든 입력 변수 편집기를 제공하는 Rive 편집기는 아닙니다. Rive Canvas 런타임의 렌더링 지원 범위가 적용되므로 일부 고급 효과는 원본 편집기와 다르게 보일 수 있습니다.

JavaScript와 WASM은 앱 폴더의 `Assets\Rive`에서 읽습니다. 파일 내용은 메모리로 전달하며 외부 CDN·URL 리소스를 가져오지 않습니다. 외부 이미지·폰트가 필요한 파일은 일부 내용이 보이지 않을 수 있으므로 리소스를 파일에 포함해 내보내 주세요.

Microsoft Edge WebView2 Runtime이 없으면 설치 안내가 표시됩니다. 다른 파일 형식은 계속 사용할 수 있습니다. 브라우저 프로필은 `%LOCALAPPDATA%\MoaView\RiveWebView`에 생성됩니다. 앱 제거 시 앱을 종료한 뒤 이 폴더를 지우면 Rive 브라우저 캐시도 제거됩니다.

## PureRef 포함 이미지 보기

`.pur` 파일 안에 저장된 PNG/JPEG 이미지를 목록에서 선택해 확인합니다. 첫 이미지를 자동으로 표시하며 확대·축소·화면 맞춤·회전을 사용할 수 있습니다. 이미지 선택을 바꾸면 회전과 배율이 초기화됩니다. PureRef 설치는 필요하지 않습니다.

지원 범위는 **포함 이미지 확인**입니다. 보드의 위치·크기·회전·잘라내기·중복 배치, 메모·그룹·드로잉은 재현하지 않습니다. 저장된 썸네일과 원본 이미지가 함께 나올 수 있으며 첫 이미지를 보드 전체라고 판정하지 않습니다. PNG/JPEG 이외의 포함 이미지와 외부 연결 파일은 읽지 않습니다. 목록 순서는 파일 내부 저장 순서이며 원래 보드의 표시 순서와 다를 수 있습니다.

알려진 PureRef 헤더 뒤에서 완결된 PNG/JPEG 데이터를 찾는 방식입니다. PNG는 청크 길이/CRC, JPEG는 세그먼트와 스캔 경계를 확인합니다. 손상된 후보를 건너뛴 경우 왼쪽에 일부 데이터 제외 안내를 표시하며, 정상 이미지가 없으면 오류와 PNG 내보내기 안내를 표시합니다. 원본은 메모리로 읽고 파일 핸들을 해제하며, 외부 프로그램 실행·디스크 추출·URL/외부 이미지 접근은 하지 않습니다.

형식은 공개 표준이 아닙니다. [1.10/1.11.1 포맷 연구](https://github.com/FyorDev/PureRef-format)를 참고해 자체 구현했으며 외부 미리보기 앱 소스는 가져오지 않았습니다. [PureRef 공식 저장 안내](https://www.pureref.com/handbook/2.0/saveload/)에 따르면 2.0에서 저장 구조가 변경되었습니다. 자동 테스트는 합성 헤더와 실제 PNG/JPEG 인코더 출력으로 수행했으며 **PureRef 앱이 저장한 1.x/2.x 실제 파일에 대한 호환성 검증은 아직 남아 있습니다.** 모든 버전의 PUR 파일을 지원한다고 보장하지 않습니다. 열리지 않거나 전체 배치가 필요하면 PureRef에서 보드를 PNG로 내보낸 뒤 여세요.

## 미리보기 한도

| 대상 | 한도 |
| --- | --- |
| 압축 파일·PDF·Office·HWP·PUR 및 TAR.GZ 압축 해제 크기 | 128 MB |
| 압축 내부 항목 수 | 4,000개 |
| 압축 내부 개별 항목 압축 해제 크기 | 32 MB |
| 비트맵 이미지 / 웹 이미지 / SVG / 글꼴 | 128 MB / 32 MB / 4 MB / 32 MB |
| PDF 페이지 렌더링 | 가로·세로 최대 1,800픽셀 |
| 전용 보기가 없는 파일의 내용 검사 / 바이너리 표시 | 앞 512 KB / 1,024바이트 |
| 일반 텍스트 파일/ZIP 내부 텍스트 | 4 MB |
| 문서 XML 한 항목 / 문서 전체 XML | 8 MB / 32 MB |
| HWP 본문 압축 해제 합계 | 32 MB |
| 문서 구역·시트·슬라이드 수 | 256개 |
| 표시 텍스트 | 문서 전체 30만 자, 초과분 생략 안내 |
| 마크다운 서식 미리보기 | 10만 자, 구성 요소 5,000개, 중첩 32단계 |
| 이미지 해상도 | 6,400만 픽셀 |
| RIV 파일 | 16 MB |
| PUR 포함 이미지 수 / 개별 데이터 | 512개 / 32 MB |
| PUR 손상 후보 탐색 / 파싱 누적량 | 1,024회 / 256 MB |

파일 크기·항목 수·탐색 한도를 넘으면 오류 안내를 표시합니다. PUR 개별 이미지 제한을 넘은 후보는 제외하고 부분 결과를 안내할 수 있습니다. 큰 문서·압축파일의 내용 추출과 이미지 디코딩은 동기 처리하므로 파일을 여는 동안 창 반응이 지연될 수 있습니다. PUR은 전체 파일 스냅샷과 선택한 이미지 하나를 보유하므로 고해상도 이미지의 디코딩 중에는 수백 MB의 메모리가 필요할 수 있습니다.

## 개발 검증

`dotnet build -m:1` 및 `dotnet test tests/MoaView.Tests/MoaView.Tests.csproj`로 검증합니다. 테스트 실행기는 localhost 통신이 가능해야 하며 Rive 통합 테스트에는 WebView2 Runtime과 대화형 Windows 데스크톱이 필요합니다.

2026-11-05 기준 전체 123개 테스트가 통과했습니다. ZIP 손상·암호화·CRC·크기 제한, 문서 관계 순서와 UTF 텍스트, HWP 복합 저장소 및 압축, WPF 구역 선택/파일 전환을 검증했습니다. Rive는 공식 테스트 샘플을 실제 런타임으로 재생하고 캔버스 픽셀·일시정지·다시 열기·손상 복구를 확인했습니다.
